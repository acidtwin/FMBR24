Sidebar header — three options

Replaces the two-line “club name / file name” block above MAIN. Each slice is the real 192px sidebar with the carbon texture at 22%. None of them shows the save file name; the club name and dates already live in the masthead and on Save Info.

A · Brand anchor

The header never changes. Wordmark on top, then one status line: is a save open, is there anything unsaved, and what in-game date is it. Answers “what state is the app in?” without repeating any name.

Two QLabels (mark 26×26 with radius 4 + wordmark) in an HBox, one rich-text QLabel for the status line. Nothing wraps, so height is fixed at 76px.

B · Browsed-club context

Shows what Club, Squads and Club Staff are about to act on. The browsed club changes when you search, so this is the one piece of sidebar context that is not already on screen elsewhere. “Your club” vs “Another club” tells you at a glance if you are editing your own squad.

Brand row (18px mark + QLabel), 1px divider, then HBox: 32×32 badge QLabel + VBox of two QLabels. Name and sub use setWordWrap(True); the badge holds up to two initials. Grows to a second name line, never truncates.

C · Manager identity

The save's human, always in view. Initials chip, manager name, managed club, under a quiet wordmark. Reads like a signed-in account; the browsed club stays in the masthead. Least new information of the three, because Save Info already lists the manager.

Wordmark QLabel, then HBox: 32×32 initials QLabel + VBox of name and club QLabels (word-wrapped). Initials come from manager_name; unemployed shows “No club”.
