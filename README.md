# FM Backroom 24 (FMBR24)

PyQt6 desktop tool for viewing and editing Football Manager 2024 save files on Linux: club overview, squads, staff, scouting reports, shortlist, save info and homegrown patching.

## Run

```bash
pip install -r requirements.txt
python main.py
```
